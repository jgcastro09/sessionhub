# TASK-0003 — Otimizar a regra de prompt para criação de Cards por IA

## Summary

Aprimorar o botão global de cópia para orientar uma IA a preparar Cards completos com Prompt Detalhado técnico e orçamento de tokens.

## Detailed Description

<!-- task-board:description:start -->
A ação global Copiar Regra de Prompt deve fornecer o meta-prompt usado antes de um Card existir. A IA deve devolver os campos compatíveis com o Task Board, manter a Descrição Detalhada como registro completo e gerar o Prompt Detalhado para a IA com estrutura técnica, deduplicação segura e limite de 9.000 tokens sem perda de requisitos únicos.
